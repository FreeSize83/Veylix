# Veylix 🐝

Современный десктопный интерфейс для управления **zapret** и проверки подключения к Discord, YouTube и другим сервисам.

Veylix — это приложение для Windows, которое делает работу с [zapret-discord-youtube от Flowseal](https://github.com/Flowseal/zapret-discord-youtube) удобнее: вместо запуска `.bat`-файлов вручную — понятное окно с выбором стратегий, проверкой доступности сервисов, диагностикой и журналом.

Цель Veylix — дать простой способ включить обход, подобрать рабочую стратегию, понять, что происходит с подключением, и спокойно обновляться.

> **Статус проекта:** Veylix находится в стадии активной разработки. Некоторые функции могут работать не во всех конфигурациях, а результат обхода зависит от вашей сети и провайдера.

## ✨ Возможности

- **Включение одной кнопкой** — запуск и остановка обхода без консольных окон; вывод `winws.exe` попадает в журнал.
- **Стратегии Flowseal без изменений** — Veylix читает оригинальные `general*.bat` и запускает `winws.exe` с теми же параметрами.
- **Автоподбор стратегии** — проверяет стратегии по очереди на адресах Discord и YouTube, оставляет текущую, если она работает, подтверждает победителя повторной проверкой и объясняет свой выбор.
- **Лаборатория стратегий** — тест выбранной стратегии с возвратом прежнего состояния, сравнение по результатам и задержке, рекомендация с объяснением, «предпочтительная» стратегия.
- **Честная проверка доступности** — по слоям DNS → TCP → TLS → HTTP с повтором неудачных попыток; различает таймаут, сетевую ошибку и подтверждённую недоступность. Проверка сертификатов не отключается.
- **Network Pulse** — мониторинг времени установки соединения с контрольными адресами с графиком истории (запускается только вручную, интервал от 30 секунд).
- **Схема подключения** — живая схема «ПК → обход → сервисы» по реальным результатам проверок.
- **Помощник** — объясняет результаты диагностики простым языком: факты отдельно от предположений, уровень уверенности и конкретные шаги. Работает локально, без внешних сервисов.
- **Центр диагностики** — права, файлы, процессы `winws.exe`, драйвер WinDivert, конфликтующие программы, VPN, прокси, DNS; отчёт можно скопировать без личных данных.
- **Журнал и история событий** — поиск, фильтры, экспорт (имя пользователя, компьютер, полные IP-адреса и токены скрываются), статистика сеанса.
- **Палитра команд** — `Ctrl+K`: быстрый поиск и запуск любых действий, горячие клавиши, закрепление на главной.
- **Оформление** — 9 тем (`Cream Light`, `Graphite Dark`, `Veylix Purple`, `Veylix Mint`, `Liquid Glass`, `Bee Night`, `Sunset Hive`, `Aurora`, `Morning Meadow`), светлый/тёмный режим по системе или по расписанию, Theme Studio с экспортом своей темы и пчёлка-компаньон.
- **Трей и автозапуск** — работа в фоне, добровольный запуск вместе с Windows.
- **Обновления** — проверка и установка новых версий Flowseal и самого Veylix с проверкой SHA-256 и автоматическим откатом при неудаче.

Функции и их доступность могут меняться от версии к версии.

## 🖥️ Требования

- Windows 10 или Windows 11 (x64).
- .NET Framework 4.8 — уже входит в Windows 10 (1903+) и Windows 11, устанавливать ничего не нужно.
- **Права администратора** — они нужны драйверу WinDivert, через который работает `winws.exe`. Windows спросит их при запуске.
- Подключение к интернету для проверок доступности и обновлений.

Отдельно устанавливать zapret не нужно: файлы `zapret-discord-youtube` уже встроены в `Veylix.exe` и распаковываются при первом запуске в `%LOCALAPPDATA%\Veylix\zapret`.

## ⚠️ Антивирусы

Антивирусы нередко помечают `winws.exe` и WinDivert как `HackTool` — это ложное срабатывание на драйвер перехвата пакетов.

Если файлы пропадают, добавьте `%LOCALAPPDATA%\Veylix` и папку с `Veylix.exe` в исключения антивируса. **Сам антивирус отключать не нужно.**

## 📥 Установка

### Вариант 1. Скачать готовый релиз

1. Откройте [страницу релизов Veylix](https://github.com/FreeSize83/Veylix/releases).
2. Скачайте файл `Veylix-X.Y.Z-win-x64.zip` из последнего релиза.
3. Распакуйте архив в любую папку (лучше без экзотических символов в пути).
4. Запустите `Veylix.exe` и подтвердите запрос прав администратора.

Настройки и журналы хранятся в `%LOCALAPPDATA%\Veylix`. Если рядом с `Veylix.exe` лежит папка `zapret` (с `bin\winws.exe` внутри), Veylix будет использовать её вместо встроенных файлов.

> Исходный архив `Source code` на странице релиза — это исходники, а не готовая программа. Для запуска нужен `Veylix-X.Y.Z-win-x64.zip`.

### Вариант 2. Собрать из исходного кода

Сборке не нужны Visual Studio, NuGet или другие инструменты: используется компилятор `csc.exe`, который уже есть в Windows вместе с .NET Framework 4.x.

```bat
git clone https://github.com/FreeSize83/Veylix.git
cd Veylix
build.bat
```

Готовый файл появится в `dist\Veylix.exe` — это один исполняемый файл, все файлы обхода уже внутри.

Дополнительно:

```bat
build.bat test
```

Сборка и автотесты.

```bat
release.bat
```

Сборка, тесты и пакет релиза `release\Veylix-X.Y.Z-win-x64.zip` с контрольной суммой (порядок публикации — в `RELEASING.txt`).

## 🚀 Начало работы

1. Запустите Veylix — на главной будет кнопка питания, проверка доступности и схема подключения.
2. Нажмите **«Проверить»** (или `F5`), чтобы увидеть, что доступно без обхода.
3. Выберите стратегию на странице «Стратегии» или запустите «Автоподбор».
4. Нажмите кнопку питания — после запуска проверка доступности выполнится автоматически.
5. Если что-то не работает, откройте «Помощник» (`Ctrl+8`) или «Диагностику» (`Ctrl+D`) — рядом с ошибками есть кнопка «Как исправить?».
6. После изменения стратегии, IPSet или игрового фильтра повторите проверку.

> Успешная проверка одного сервиса не означает, что доступны все остальные.

## 🔄 Обновления

### Veylix

Veylix обновляется сам: **«Обновления» → «Проверить обновления» → «Обновить»**.

Пакет скачивается только из релизов [этого репозитория](https://github.com/FreeSize83/Veylix/releases), проверяется по SHA-256 из данных GitHub, прежняя версия сохраняется рядом и автоматически возвращается, если новая не запустится. Настройки и журналы не затрагиваются. Ничего не скачивается без вашего подтверждения.

### Flowseal (zapret)

Flowseal (zapret) обновляется там же, из [официального репозитория Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube) — релизы: с проверкой контрольной суммы, переносом ваших списков и возможностью вернуть прошлую версию.

Перед обновлением просматривайте описание изменений — Veylix показывает его в окне обновления.

## 🛠️ Устранение неполадок

### Сервис отображается как недоступный, хотя на самом деле работает

1. Повторите проверку — неудачные адреса и так перепроверяются, но сеть может быть нестабильной.
2. Откройте «Диагностику»: там видно, на каком этапе (DNS, TCP, TLS, HTTP) и для какого адреса оборвалось соединение.
3. Проверьте, не включён ли VPN или системный прокси — тогда проверки показывают их работу, а не работу обхода.
4. Убедитесь, что обход действительно включён и выбрана нужная стратегия.
