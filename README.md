# Veylix 🐝

**Современный десктопный интерфейс для управления zapret и проверки подключения к Discord, YouTube и другим сервисам.**

Veylix — это десктопное приложение, разработанное для того, чтобы сделать работу с [zapret-discord-youtube от Flowseal](https://github.com/Flowseal/zapret-discord-youtube) более удобной с помощью графического интерфейса.

Цель Veylix — предоставить доступный способ управления стратегиями подключения, проверки доступности сервисов, мониторинга активности приложений и упростить повседневную настройку.

> **Статус проекта:** Veylix находится в стадии активной разработки. Некоторые функции могут быть реализованы не полностью, а совместимость может зависеть от вашей системы и конфигурации.

## ✨ Возможности

- **Графический интерфейс** — управляйте доступными опциями, не полагаясь исключительно на командную строку.
- **Управление стратегиями** — просматривайте и выбирайте доступные стратегии подключения.
- **Автоматический выбор стратегии** — тестируйте доступные стратегии, чтобы найти подходящую конфигурацию.
- **Проверка подключения** — проверяйте доступность поддерживаемых сервисов.
- **Журнал активности** — просматривайте результаты диагностики, события в приложении и ошибки.
- **Быстрый доступ** — доступ к основным функциям из главного окна.
- **Кастомизация** — улучшение внешнего вида и удобства использования приложения по мере разработки. 

 Функции и доступность могут меняться от версии к версии. 

 ## 🖥️ Требования

Перед использованием Veylix убедитесь, что у вас есть:

- поддерживаемая версия Windows.
- совместимая установка [zapret-discord-youtube от Flowseal](https://github.com/Flowseal/zapret-discord-youtube), если это требуется для вашей версии Veylix.
- разрешение на запуск необходимых сетевых инструментов и процессов.
- подключение к интернету для загрузки релизов и проверки обновлений.

 Для некоторых операций могут потребоваться права администратора. Предоставляйте их только в случае необходимости и после того, как поймёте, что именно запрашивает приложение. 

 ## 📥 Установка

### Вариант 1. Скачайте релиз

1. Откройте страницу [релизов Veylix](../../releases). 
2. Скачайте последний релиз, доступный для вашей системы. 
3. Распакуйте архив, если загруженный файл был сжат. 
4. Следуйте инструкциям по установке для конкретной версии, прилагаемым к релизу. 
5. Запустите `Veylix.exe`, если в релизе есть готовый исполняемый файл. 
6. При необходимости укажите путь к уже установленной программе zapret. 

**Примечание.** Если релиз еще не вышел, воспользуйтесь приведенными ниже инструкциями по установке из исходного кода. 

### Вариант 2. Запуск из исходного кода

1. Скачайте или клонируйте этот репозиторий. 
2. При необходимости распакуйте файлы проекта. 
3. Установите зависимости, необходимые для работы проекта. 
4. Следуйте инструкциям по сборке и запуску, приведенным в репозитории. 

Клонируйте репозиторий с помощью Git:

```bash
git clone <YOUR_REPOSITORY_URL>
cd <YOUR_REPOSITORY_FOLDER>
```

Замените заполнители на фактический URL вашего репозитория на GitHub и название папки. 

Точные команды для установки зависимостей и запуска приложения зависят от фреймворка проекта.  Обратитесь к соответствующим файлам конфигурации и скриптам сборки, входящим в состав репозитория. 

### Сборка исполняемого файла

Если вы хотите собрать Veylix самостоятельно:

1. Установите инструменты разработки, необходимые для работы проекта. 
2. Установите зависимости проекта.
3. Запустите прилагаемый скрипт сборки или следуйте инструкциям по сборке для конкретной платформы.
4. Найдите сгенерированный исполняемый файл в выходном каталоге, указанном в конфигурации сборки.

Не думайте, что в исходном архиве уже есть готовый к запуску исполняемый файл.

## 🚀 Начало работы

После запуска Veylix:

1. Ознакомьтесь с доступными стратегиями подключения.
2. Убедитесь, что доступны необходимые файлы и конфигурация zapret.
3. Запустите проверку подключения.
4. Выберите подходящую стратегию или воспользуйтесь автоматическим выбором стратегии, если такая возможность поддерживается.
5. Если проверка не пройдена, просмотрите журнал активности.
6. Повторите тест после изменения конфигурации.

Успешное прохождение проверки подключения к одному сервису не означает, что все остальные сервисы доступны.

## 🛠️ Устранение неполадок

### Сервис отображается как недоступный, хотя на самом деле он работает

- Запустите проверку подключения еще раз.
- Проверьте, относится ли результат к веб-сайту, конечной точке API или конкретной функции приложения.
- Просмотрите журнал приложения.
- Убедитесь, что выбранная стратегия действительно активна.

### Veylix не запускается

- Проверьте, поддерживается ли ваша версия для Windows.
- Убедитесь, что на компьютере есть необходимые файлы приложения.
- Изучите сообщения об ошибках, возникающие при запуске.
- Если вы собирали проект самостоятельно, убедитесь, что все зависимости установлены правильно.

### Стратегия не работает

- Попробуйте другую доступную стратегию.
- Проверьте конфигурацию установки zapret.
- Просмотрите логи на предмет соответствующих ошибок.
- Не меняйте сетевые настройки системы, если не понимаете, к каким последствиям это может привести.

Если проблема не устранена, создайте задачу и укажите версию приложения, версию Windows, шаги для воспроизведения проблемы и соответствующие логи. Перед отправкой диагностической информации удалите личную информацию и конфиденциальные данные.
