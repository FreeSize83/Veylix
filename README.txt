Veylix — лаунчер обхода блокировок (на базе zapret-discord-youtube от Flowseal, 1.10.3)
=====================================================================================
Ранее назывался BeeBot.

КАК ПОЛУЧИТЬ .EXE
  1. Распакуйте папку куда угодно.
  2. Дважды кликните build.bat  ->  появится dist\Veylix.exe
     (нужен только .NET Framework 4.x — он уже есть в Windows 10/11).
  3. Veylix.exe — один файл, все файлы обхода (winws.exe, WinDivert, списки, .bat) уже внутри.
     При первом запуске он распакует их в %LOCALAPPDATA%\Veylix\zapret.
  4. Windows спросит права администратора — они нужны драйверу WinDivert.

  Тесты:  build.bat test        (сборка + автотесты без сети)
          dist\VeylixTests.exe --net   (дополнительно реальные сетевые проверки и загрузка релиза)

РАЗДЕЛЫ
  * Главная — кнопка питания, состояние, проверка доступности (интернет, Discord, YouTube),
    режимы (стратегия, IPSet, игровой фильтр, автоподбор), быстрые действия, последние события.
  * Стратегии — все general*.bat; у каждой показан последний результат проверки. Автоподбор:
    сначала проверяется интернет; текущая стратегия проверяется первой и остаётся, если работает;
    каждая стратегия проверяется на 3 адресах Discord и 3 адресах YouTube; победитель подтверждается
    контрольной проверкой; если идеальной нет — остаётся лучшая (или прежняя), с объяснением.
  * Диагностика — права, файлы Flowseal, процессы winws.exe, драйвер WinDivert, служба BFE,
    служба zapret, конфликтующее ПО, VPN, DNS, системный прокси, TCP timestamps и проверка
    сервисов по слоям DNS -> TCP -> TLS -> HTTP. Отчёт можно скопировать/сохранить (личные данные скрыты).
  * Журнал — время, уровень, поиск, фильтр, экспорт в .txt (без имени пользователя, компьютера,
    полных IP, паролей и токенов). Полный журнал: %LOCALAPPDATA%\Veylix\veylix.log.
  * Обновления — версия Flowseal, описание релиза, проверенная установка и откат.
  * Настройки — темы, автозапуск, трей.

ОБНОВЛЕНИЕ VEYLIX
  * Обновления → «Обновление Veylix»: «Проверить обновления», затем «Обновить до X.Y.Z». Veylix скачает
    пакет из релизов github.com/FreeSize83/Veylix, проверит SHA-256, перезапустится и при неудаче
    сам вернёт прежнюю версию (она остаётся рядом как Veylix.exe.backup-<версия>). Настройки и журналы
    в %LOCALAPPDATA%\Veylix не затрагиваются. Журнал установки: %LOCALAPPDATA%\Veylix\updates\update.log.
  * Проверка при запуске включается в той же карточке; скачивание — только по вашей кнопке.
  * Как выпускать релизы — RELEASING.txt (release.bat собирает пакет и контрольную сумму).
  * Проверка полного цикла на локальном пакете: powershell -ExecutionPolicy Bypass -File tests\update-e2e.ps1

ВОЗМОЖНОСТИ 2.2
  * Пчёлка-компаньон на главной (во всех темах): отдыхает, работает, проверяет, тревожится при ошибке,
    радуется восстановлению связи — состояние берётся из реальных событий. Щелчок по ней открывает
    помощника. Скрыть пчёлку и выключить её анимацию можно в Theme Studio.
  * Помощник (раздел «Помощник», Ctrl+8, кнопки «Как исправить?» у ошибок): локальные правила без
    интернета. Показывает факты отдельно от предположений, уровень уверенности (подтверждено /
    вероятно / возможно) и шаги. Действия, меняющие состояние обхода, — только после подтверждения.
    Никогда не советует отключать антивирус, защиту или проверку сертификатов.
  * Theme Studio (Настройки): акцентный цвет (с автокоррекцией контраста), свечение и блики, скругление,
    плотность списков, скорость анимаций, пчёлка. Живой предпросмотр, сброс, экспорт и импорт
    в файл .veylix-theme.json (только данные, каждое поле проверяется, размер до 16 КБ).

ВОЗМОЖНОСТИ 2.1
  * Палитра команд — Ctrl+K: поиск любого действия, стрелки + Enter, Ctrl+P или ☆ закрепляет
    команду в «Быстрых действиях» на главной. Горячие клавиши: F5 — проверить сервисы,
    Ctrl+D — диагностика, Ctrl+Shift+E — вкл/выкл обход, Ctrl+Shift+P — Network Pulse,
    Ctrl+U — обновления, Ctrl+1…7 — разделы, Ctrl+, — настройки.
  * Network Pulse — по кнопке раз в 30 с … 5 мин измеряет время TCP+TLS-соединения с ya.ru,
    discord.com, www.youtube.com, www.google.com (это не ICMP ping). График истории (30/60/120
    точек), изменение к прошлому замеру, время последнего успеха. «Недоступен» — только после
    двух неудач подряд.
  * Схема подключения на главной: ПК → движок winws → сервисы. Цвет — последний реальный
    результат проверки, «нет данных» — если проверки не было; бегущая точка означает, что обход
    активен на участке (это не трафик). Наведение — подробности, щелчок — диагностика/стратегии.
  * События: хронология сеанса (обход, стратегии, потеря/восстановление соединения, проверки,
    обновления, ошибки) с фильтрами и переходом в раздел; статистика сеанса — время работы
    приложения и отдельно обхода, число проверок, измерений Pulse, ошибок. Только память, никуда
    не отправляется.
  * Лаборатория стратегий: тест выбранной стратегии с возвратом прежнего состояния, сравнение
    по результату, рекомендация с объяснением, «предпочтительная» стратегия (выбирается при запуске).
  * Уведомления внутри окна: повторы объединяются, необязательные можно выключить в настройках.

ПРОВЕРКА ДОСТУПНОСТИ
  Различаются: таймаут (и на каком этапе), сетевая ошибка, подтверждённая недоступность
  (неудача на всех адресах при повторной проверке и работающем интернете) и «нет интернета» —
  в последнем случае Veylix не сообщает о блокировке сервиса. Проверка сертификатов TLS не отключается.

ТЕМЫ
  Cream Light, Graphite Dark, Veylix Purple, Veylix Mint, Liquid Glass.
  Иллюстрированные (векторные сцены и пчёлка-талисман, чьё лицо показывает состояние обхода):
  Bee Night (ночь, облака, радиовышка), Sunset Hive (закат), Aurora (северное сияние) — тёмные;
  Morning Meadow (утренний луг) — светлая. В режимах «Как в Windows» и «По расписанию» светлым
  вариантом для них служит Morning Meadow, тёмным — выбранная тема.
  Режим: «Вручную», «Как в Windows» или «По расписанию» (светлая 07:00–19:00, тёмная в остальное время).
  Liquid Glass использует системное размытие Windows 11 22H2+ (Acrylic). Если оно недоступно
  (Windows 10, отключена прозрачность, нет ускорения, удалённый стол) или включён «Упрощённый режим»,
  остаются полупрозрачные слои без размытия и без движения фона.

ОБНОВЛЕНИЕ FLOWSEAL
  Источник — https://github.com/Flowseal/zapret-discord-youtube (тот же, что в service.bat).
  «Проверить обновления» сравнивает версию из service.bat с последним релизом и показывает описание.
  Установка — только по кнопке и после подтверждения: .zip скачивается с GitHub, проверяется по SHA-256
  из данных релиза GitHub (поле digest; без него автоустановка не предлагается), распаковывается
  во временную папку с защитой от выхода за её пределы, проверяется состав, переносятся ваши списки,
  IPSet и игровой фильтр; текущая версия сохраняется рядом как zapret.backup-*; при ошибке — откат.
  Кнопка «Вернуть прошлую версию» восстанавливает последнюю резервную копию.

АВТОЗАПУСК И ТРЕЙ
  Автозапуск — по желанию, задание «VeylixLauncher» в Планировщике (старое «BeeBotLauncher»
  удаляется при включении/выключении). Крестик при работающем обходе прячет окно в трей (можно отключить).
  Повторный запуск Veylix.exe просто показывает уже открытое окно.

ПЕРЕНОС С BEEBOT
  При первом запуске настройки и пользовательские списки копируются из %LOCALAPPDATA%\BeeBot
  в %LOCALAPPDATA%\Veylix. Старая папка не удаляется.

СВОИ ФАЙЛЫ ВМЕСТО ВСТРОЕННЫХ
  Если рядом с Veylix.exe лежит папка zapret (с bin\winws.exe внутри), будет использована она.

АНТИВИРУС
  winws.exe / WinDivert часто определяются как "HackTool" (ложное срабатывание — драйвер перехвата
  пакетов). Добавьте %LOCALAPPDATA%\Veylix и папку с Veylix.exe в исключения.

УДАЛЕНИЕ
  Выключите автозапуск в настройках, закройте Veylix (трей -> Выход), удалите %LOCALAPPDATA%\Veylix.

ЛОГ ОШИБОК: %LOCALAPPDATA%\Veylix\crash.log
